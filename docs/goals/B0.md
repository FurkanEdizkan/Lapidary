## Why

The owner wants Phase 6 and the loose ends built by several Claude Code sessions at once, one goal each, with one
lead integrating (decided 2026-09-21). The rules for that lived in one session's memory, and the machine had three
ways for parallel sessions to break each other: a shared `target/`, one test database, and no division of the files
everyone touches.

## Facts checked (as of `3964524`)

- One `target/` shared by every worktree through `CARGO_TARGET_DIR`: 134 GB of `debug/deps`, cleared on 2026-09-21
  with the owner's leave. A worktree with `CARGO_TARGET_DIR` unset builds into its own `target/`.
- sqlx 0.9 names each `#[sqlx::test]` database after the test's path, the same in every run, and drops it first.
- The git hooks (`.githooks/`, `core.hooksPath` absolute) apply to every worktree; `cargo xtask` is built per target
  directory, and derives the workspace root from its own manifest path.
- `std::fs::File::lock` is stable (Rust 1.89); the toolchain is 1.95. No new crate is needed for the lock.
- The impeccable hooks were in the untracked `.claude/settings.local.json`; `.codex/hooks.json` already tracks the same
  two commands.
