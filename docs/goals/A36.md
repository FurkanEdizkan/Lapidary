## Decisions

## Record

- **The sign-in wall:** `GET /api/wall` names each picture `/api/wall/{image id}`, and that route reads the picture by
  id under the whole wall condition (shared with everyone, not left out, the switch on); anything else, a stored
  picture's hash included, is the same 404. On the check stack with all 19,194 parts shared: the list is **4.7 kB**
  (48 pictures inline averaged 52 kB each, about 3.3 MB as base64); the 48 pictures follow as images, 2.6 MB in 0.7 s,
  still `no-store`. API tests cover private, hidden, the switch off and an unknown id.
- **The padded STL:** the one in the corpus is `GrizaLingeringWound_42mm.stl`, 700,100 triangles and 200 bytes after
  them. It now reads (watertight, 49 × 62 × 31 mm); a file shorter than its count is still refused, and text is still
  read as text. The 1,560 refusals an earlier check stack showed were macOS `._*.stl` resource forks (4 kB, no
  triangles) whose dot the copy script had renamed away; the scan skips them by name in the real layout.
- **CPU:** `cpus: "${LAPIDARY_CPUS:-2.0}"` in compose, documented in `.env.example`. The default is unchanged.
