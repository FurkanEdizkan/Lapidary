**Status:** merged
**Branch:** `feat/pages-pass`
**Wave:** 13 · **Kind:** web · **Depends on:** A21 · **Migrations:** —

## Why

The redesign (REDESIGN.md, owner 2026-10-18) and A17's audit: the read-only Port field looks editable, People's rows
read "rig rig admin you" with no labels, the dashboard's empty state points 1200px away, and the pages beyond the grid
were never given the page anatomy.

## Decisions

- Every page on `Page.ts`'s anatomy and DESIGN.md: one Headline, an Ash lead, label-over-rule sections, one standing
  control. Read-only facts read as facts, not inputs. Lists say what each column is.
- The dashboard's empty state carries its own Add a widget; its dialogs get presence (A22's pattern). No polling.

## Done when

Each page at 1440 and 390 matches DESIGN.md; the rig and the gate pass.

## Record

Built, page by page on `Page.ts` and DESIGN.md:

- **Dashboard.** The empty board carries its own standing **Add a widget** under a Scope title; the header's is drawn
  only once the board has a widget, so the name stays unique (the tests find it by role). After the first add, focus
  goes to the header's Add a widget (the empty state's opener leaves with the empty state; a new test holds it and a
  mutation of it fails). The five dialogs — Add a widget, a widget's settings, Add a group, Rename group, Remove
  group — mount in `Presence` as A22 did, each verb standing at a right-aligned `DIALOG_FOOT`; dialog fields moved to
  Bench Grey. "This arrangement is remembered by this browser" moved after the board, 12px Graphite. A failed first
  load is an alert with a standing Try again. No polling: `no-polling.test.ts` green.
- **Settings.** Model sites, Adding models, Server and a new **Folders** section each open on a label over a rule.
  A port deploy/.env fixes, or one a non-admin cannot move, is a fact (`FACT`: mono on the Bench Grey well, no
  Edge) in a `<dl>`, not a disabled input (new test); the models folder and Lapidary's own files read the same way,
  and an unknown path stays a sentence in Archivo. Site-row controls are one 32px height (`QUIET`); Save stands once
  a key is typed. Hints are `HINT`: 12px Graphite at 60ch.
- **People.** Accounts under their own label, rows divided rather than boxed (no stray rule before Add a person).
  Each row: the name in Title, **You** beside your own, then a labelled username (only when it is not already the
  name) and a labelled role, Admin or Member (new `people.test.tsx`). Add a person is one 28rem column.
- **Profile.** Name form under the lead, username as its placeholder; Save stands only once the name changed; Change
  password is quiet and visibly disabled until both fields are filled.
- **Tags.** The empty index adds a standing **Open a model** into the grid. **Shared with me** gains its Ash lead;
  its empty and failed sentences sit under it at 70ch.
- `Page.ts` gains `FACT` and `HINT`, and `STANDING`/`QUIET` a disabled state (50%, no lift). `Field`'s hint is
  12px Graphite at 60ch (was 11px Ash), which also reaches sign-in and setup.
