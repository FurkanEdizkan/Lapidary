# A21 — App shell, grid cards, route enter

**Status:** merged
**Branch:** `feat/shell-and-cards`
**Wave:** 13 · **Kind:** web · **Depends on:** A18, A17 · **Migrations:** —

## Why

The redesign (REDESIGN.md, owner 2026-10-18) and A17's audit (A17.md § Audit): the header takes three rows at 390,
four controls weigh the same, most pages mark no current place, and a library without pictures is forty identical
"STL" squares.

## Decisions

- Follow DESIGN.md (A17) for the header, the places marker, cards and skeletons; REDESIGN.md § "Taken from A17's audit"
  for the one-row header under `md`, a current place on every page, and the still lattice standing in for a missing
  picture on cards.
- Every accessible name the rig and the tests use stays; a route enters with `Rise`, enter only.

## Done when

Grid and header at 1440 and 390 match DESIGN.md, the rig and the gate pass, and the entry chunk stays within budget.

## Record

Built on main after A19 and A22 (rebased twice, clean). Rig ran on the tree at 22b1639; the last commit (the account marker, list rows) is gate-checked only.

**Shell (`AppFrame.tsx`).**
- One 56px row at every width. Upload stands; Library and Import are quiet (`Page.ts` `QUIET`; `Menu`'s text
  variant is quiet now, which also quiets View). Under `md`, a new `tools` slot (Library, Import) and the places move
  into the drawer, rendered there only while it is open so `library-menu` and the Places landmark exist once; search
  folds to an icon that opens it across the row (kept in the DOM, so `/` and the rig's selector still find it); Upload
  shows its icon alone, its text unchanged for `pressUpload`.
- A current place on every page: one `Indicator` (`place-marker`, 2px Quicklime, 180 ms on the curve via a new
  `move="base"` on `Indicator`, which also drops to zero under reduced motion). Part page and Tags (`current="part"`,
  `"tags"`) mark Parts and keep it a link with no `aria-current`; Profile, Settings and People mark the account button.
  The drawer's stacked places carry a static 2px rule instead, so only one element holds the layout id, and the
  account button's marker is a plain line, not the travelling one (under `md` the places are `display: none`, so a
  shared marker would fly in from a 0×0 box at the corner). Measured in
  CDP: the marker travels from x 142 / 29 px wide to x 194 / 61 px across the page remount in about 175 ms.
- Scribe Line once scrolled (scroll listener; a transparent border at the top so the row never moves).
- The drawer's scrim is `Presence` + `Fade` (120 ms) in place of `scrim-in`; `overscroll-behavior: contain` on the
  drawer; a menu flips inline if its button is at the left edge (`position-try-fallbacks`).
- `index.html` theme-color `#121214`; `text-wrap: balance` on h1–h3; `touch-action: manipulation` on controls;
  `min-h-dvh` on the frame and the root; the header search on non-grid pages says Enter opens the grid.

**Route enter.** `Rise` keyed on the router's *resolved* pathname, enter only, 180 ms, 8px — inside `AppFrame` around
the page's content, not in `__root.tsx` around the `Outlet`. **Decided without the owner, and the lead's call to
reverse:** every page renders its own header, so a `Rise` around the outlet fades the whole header in on each
navigation (hiding the marker's move) and, for 180 ms, makes the drawer, scrim and skip link fixed to the transformed
wrapper. Moving it to the root is one line. Settled, the wrapper's computed transform is `none` (checked in CDP at 1440,
390 and under reduced motion). The crash page (`nav={false}`) has no enter and reads no router.

**Cards.** The figures line leads with a format chip (4px Bench Grey, mono Graphite, uppercased in CSS), then the
part number in Ash, then `≈` before the triangle count (dotted Edge underline and title; heard as "approximate"). The
detail layout holds two lines for every name so a row of footers lines up; the skeleton takes the same shape (static).
A card with no picture shows `<Lattice still />` over the lamp's pool; the format is the chip to the eye and the well's
`sr-only` word to a reader (the chip is `aria-hidden` there, so it is said once). Hover lifts 1px and brightens to Edge,
no blue. Hovering still fetches nothing (`Grid.test`).

**Empty states.** FirstRun: Import stands (the lead's first verb), "Upload a folder" is quiet; no-results and empty
category headings use Scope (15px/600).
