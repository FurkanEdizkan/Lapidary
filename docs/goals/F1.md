# F1 — Pictures without rendering

**Status:** open
**Branch:** `feat/embedded-thumbnails`
**Wave:** 7 · **Kind:** Rust + web · **Depends on:** S4 · **Migrations:** 0058

## Why

Since the pivot a card's picture is whatever a person uploaded. Many 3MF files already carry one: slicers write a
thumbnail into the package. And for an STL with no picture, the person who opens the viewer is looking at a perfectly
good one.

## Facts to check before building

- 3MF: the thumbnail is named by a relationship in `_rels/.rels` (type
  `http://schemas.openxmlformats.org/package/2006/relationships/metadata/thumbnail`), usually
  `/Metadata/thumbnail.png`; some slicers also write per-plate images (`Metadata/plate_1.png`). Use the
  relationship, fall back to nothing — not a guessed path.
- `crates/lapidary-cad/src/tmf.rs` already opens the package (its test at :781 builds one with a thumbnail).
- `crates/lapidary-api/src/images.rs::normalize` is the one path an image takes into `part_image`; ingest is in
  `lapidary-ingest`, so `normalize` may need to move to a crate both use (e.g. `lapidary-core` or a small module in
  `lapidary-storage`). Move it, don't copy it.
- `part_image.origin` check constraint: today's values, and that `og_fetched`/`rendered` have no writer.

## Rules

- A person's own picture always wins: an embedded thumbnail is added only to a part with no picture, and never
  replaces one.
- A broken or oversized embedded image is skipped with a logged reason; it never fails the ingest.
- The viewer's "use this view as the picture" uploads through the existing endpoint, origin `snapshot`.

## Stages

1. Embedded 3MF thumbnail at ingest, origin `embedded`. **Tests:** a 3MF with one gets a picture; one without
   gets none; one with a corrupt PNG ingests fine with no picture; a part with an uploaded picture keeps it.
2. Viewer button. **Tests:** web test for the button and the upload call.

## Done when

Ingesting slicer-saved 3MFs from the owner's corpus gives cards with pictures and no upload; the Record says how
many of the corpus's 3MFs carried one.
