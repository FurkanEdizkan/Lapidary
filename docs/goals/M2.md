## Record

**Done.** The header's places are **Parts** and **Dashboard**. A user icon (Phosphor `user`, vendored like
the rest) at the far right of every page opens **Profile** and **Settings**; the page you are on is
marked in it and not linked. The crash page, which cannot trust the router, has no menu.

**Profile** is this install's display name: migration 0060 makes a one-row `profile` table (a check keeps
the name 1–80 characters), `GET`/`PUT /api/profile` read and set it, a blank clears it, and the page at
`/profile` edits it. No accounts and no sign-in, as the goal says. The menu itself fetches nothing, so the
header still renders anywhere without a data client.

The removed list still exists at `/removed` until M3 takes it away; nothing links to it now.

Tests: one API test (kept trimmed, cleared by a blank, refused past 80); two header tests (two places;
Profile and Settings in the user menu, the current one marked). 434 of 434 web tests. Checked in headless
