# M3 — Delete is delete

**Status:** open
**Branch:** `chore/delete-is-final`
**Wave:** 8 · **Kind:** Rust + web · **Depends on:** M1 · **Migrations:** 0061

## Why

Owner, 2026-10-17: "we don't want a restore option; if it is deleted it is deleted." Delete removes a
part from the library immediately — its rows, pictures and tags — and **never touches the file on disk**
(M4 makes the library read your folders in place). Restore, purge, the removed list, soft delete and the
30-day quarantine go. CLAUDE.md's "delete is soft" rule is rewritten with the owner's words.

## Done when

One Delete, behind a confirmation that says the file stays; no removed list, restore or purge anywhere;
nothing reads `deleted_at`.
