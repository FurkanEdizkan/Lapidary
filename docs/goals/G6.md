### Decided without the owner

- **The three decisions are offered on Identical and Near-duplicates, and nowhere else.** G6.md
  attaches them to Near-duplicates; withholding them from Identical would mean the one case where
  folding is most obviously right could only be acted on from the queue. Variants are already
  decided, and "Similar" is top-k by shape whatever the size — a `distinct` written from it would
  record a decision about a pair nothing ever proposed. `distinct` on a byte-identical pair is
  kept even though it reads oddly, because without it an identical pair somebody means to keep
  (two deliberate copies) can never leave the queue.
- **The finished line counts parts, not groups.** G6.md's wording is "N look like parts already
  here"; counting `clusters.length` would report 1 for a batch of eleven copies of one bracket, so
  `justAdded` counts the parts added since the batch started that are in a group with something
  else. The sentence reads "3 parts just added look like other parts in this library."
- **A group's first part is what its decisions keep.** The wire sends a group largest-first and
  promises nothing else, so the heading names that part ("These look like “spares/LP-1042-03.stl”")
  and it is drawn without buttons; every other part carries all three. A group of two — the
  ordinary case — reads as a pair.
- **No "the comparison is approximate" note.** `phase-6.md` settles it: no score is shown, so
  there is no approximate figure to label. The only figure on a row is the part's own triangle
  count, and it carries `strings.parts.approximate` exactly as the grid card does.
- **The queue's groups are sorted on the client**, newest first by the newest part in each. The
  binding promises an order inside a group and none between them.
- **`web/src/lib/types.ts` gained seven re-exports** (`DuplicateCluster`, `DuplicateClusters`,
  `Fold`, `FoldPart`, `Likeness`, `PartLinkKind`, `SetLink`) as one contiguous block. It is the one
  file that may import from `../bindings`, and G6.md does not name it — flagging it as a shared-file
  edit. G5 will append its own block the same way.
- **Two test files not named by G6.md were edited, because mounting into their pages breaks them.**
  `parts.$partId.test.tsx`: eleven stubs learn `/likeness` (they answer every unknown GET with a
  `PartDetail`, which hands `Likeness`'s four arrays an object), and the section-index test now
  expects `Looks alike` before `File` and `Identity`. `removed.test.tsx`: its stub learns `/folds`,
  and `stub` takes a third `folds` argument.
- **Lane 4's accessibility item, taken** (`web/src/components/Upload.tsx`, second commit):
  `ScanProgress`'s progress line carries `role="status"`, and its unknown-batch sentence
  `role="alert"`. The line and not the block: `status` is atomic, and a region wrapping the failure
  list would re-read a hundred failed files on every poll — the same reason the upload transfer's
  own line carries it alone. No `id` was added; `getByRole('status')` is the handle a driver needs,
  and an id put there only for a test driver is scaffolding. Pinned by two existing tests in
  `index.test.tsx`, strengthened in place.

### Left for later

- **The live check.** Every test mocks `fetch`. Nothing here has spoken to G3's routes, and four
  assumptions about them are in the report to the lead (is `/folds` a bare `Fold[]`; does the link
  route normalise pair order for the table's `part_id < other_id` check; what exactly `since`
  filters; whether profiles exist by the time an upload batch finishes).
- **`ReviewOffer` asks once, when the batch finishes.** If profiling lags behind ingest, that one
  read sees only the identical parts. A resync on `GET /api/events` (G1) would fix it in a line;
  polling it would not, and `FEATURES` §8 calls per-widget polling a self-inflicted DoS.
- **The queue is not paged.** `DuplicateClusters` carries no cursor, and a library with hundreds of
  groups wants one. Same call the removed list made.
- **No bulk fold.** A group of eleven copies is ten presses. The grid's `bulk.ts` is the shape it
  would take.
