## Record

- **Budget:** taken in `index()`, which every mesh path goes through (scan, upload, inbox, site link, bundle), and
  released when it returns, before `as_added` fetches a page.
- **A reader that panics** fails its job `Permanent` rather than three times over (unit test).
- **Stale failures:** the scan forgets failed `ingest_file` rows for the paths it finds unchanged. On the 20k check
  stack, a planted failure for an indexed file was gone after one rescan.
- **Retried walk:** `note_unchanged` counts only unchanged paths with no `ingest_file` job in the batch (test: a second
  walk in the same batch keeps `total` at 3).
- **Root:** `CurrentRevision` carries its file's root, and `is_file` requires it.
- **Facets:** the format filter for materials, tags and choice fields uses `in_format`, any source file of the current
  revision, as the grid does (test with a revision holding an STL and a newer OBJ). Filtered facets at 20k: 52–56 ms
  (44 before, the cost of the grid's own test).
- **Folders:** the rollup stops at a folder it has passed (test: a two-folder cycle among 22 counts 2 each).
- **STL:** up to 1 KiB after the last declared triangle is padding; more is a wrong count and refused (tests: 200 bytes
  read, 1,400 refused).
- **20k rescan, unchanged:** 0.46 s from request to finished (the earlier 4 s was 1,560 macOS `._` refusals retried
  each scan, an artefact of a flattened test copy).
