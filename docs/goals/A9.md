# A9 — A folder browser worth the name, and New folder

**Status:** open
**Branch:** `feat/folder-browser`
**Wave:** 12 · **Kind:** Rust + web · **Depends on:** A8 · **Migrations:** —

## Why

Owner, 2026-10-18: the wizard's folder picker was a list and an Up button. It should open its own view, let a person
jump anywhere on the path or type one, and make a new folder there.

## Decisions

- The picker is a dialog: the path as clickable segments, a field to type or paste a path, the folders with icons, and
  Use this folder at the foot with why it can't be used when it can't.
- **New folder** makes one folder inside the one shown: `POST /api/settings/storage/folders` (admin) and
  `POST /api/setup/storage/folders` (setup code), `{path, name}`. A plain name only (no `/`, no leading `.`, not
  `_removed`), never over anything that exists, only where Lapidary may write, never in `/proc`, `/sys`, `/dev`, `/run`.
  It answers the new folder's listing, and the picker opens it.

## Done when

The wizard and Settings open the dialog; a folder made there can be chosen at once; the gate and the rig pass.
