# A34 — Counts that do not slow down with the library

**Status:** merged
**Branch:** `perf/counts`
**Wave:** 16 · **Kind:** db + api + web · **Depends on:** A33 · **Migrations:** —

## Why

Scale report item 2 (and item 8's dashboard timing). At 20k parts facets take 84–98 ms and the category tree 86 ms and
1.36 MB, and while a scan runs the grid asks for facets and storage again about once a second.

## Decisions

- During a scan the grid refreshes its counts at most every 5 s, and once when the scan ends.
- The facet groups come from one query rather than one per group.
- The category tree sends each folder's own name and its parent, not its whole path.
- The dashboard's widgets are timed at 20k.

## Done when

Facets under 40 ms and the tree under 400 kB at 20k; at most one facet request per 5 s during a scan; gate and rig pass.

## Record

The check stack (52 copies of the corpus's meshes under 3 MB, folders kept: 19,194 parts, 9,569 categories), from this
branch:
- **Facets beside the grid:** 84–98 ms → **42–49 ms**; with a format chosen ~200 ms → **44 ms**; a search 20 ms. The
  three groups are one read: the parts that pass the shared filters once, each part's current format worked out once
  (two sorted passes, not two lookups per part), counted three ways. What is left is that pass (~30 ms on the
  database's one CPU); a rollup refreshed on ingest is the next step if 100k parts becomes a goal. Indexes on the
  ordering were tried and saved 3 ms, so there is no migration.
- **Category tree:** 1.61 MB → **293 kB** on the wire (JSON, HTML, CSS and JS are gzipped; model files, pictures and
  downloads never are), 25–29 ms → 32–35 ms with the gzip. Its counts are each folder's own, added up the tree in Rust,
  instead of a recursive pairing of every folder with each descendant.
- **During a scan** the grid asks for facets and storage at most every 5 s and once at the end (a web test fails
  without it: 3 requests in 3 s).
- **Dashboard widgets at 20k:** storage 13–18 ms, instance storage 3–7, recent 2–5, queue 3–4, a facet 42–46; all six in
  one resolve 83–104 ms.
Rig 29/29, gate 14/14.
