# G3 — Likeness API

**Status:** open
**Branch:** `feat/likeness-api`
**Wave:** 1 · **Kind:** Rust · **Depends on:** W0 · **Migrations:** — (W0's 0047, 0048)

## Why

The part page, the review queue and the dashboard's duplicates widget all ask one question: which parts are like this
one, and what has somebody already decided about them. Design: [`phase-6.md`](phase-6.md) §§ Three kinds of alike;
Links, and folding.

## Facts checked (re-check against W0's merge)

- W0 gives `part_shape`, `part_link`, `PgShapes::record`, `PgParts::rows_by_id`, `to_card` (`pub(crate)`), the wire
  types `Likeness`, `DuplicateClusters`, `SetLink`, `FoldPart`, and `likeness::routes()` (empty).
- Soft delete is `PgParts::soft_delete`; Restore exists (`removed.tsx`). Cross-library requests answer 404 everywhere.

## Rules

- Owns: `crates/lapidary-db/src/likeness.rs` (new), the handlers in `crates/lapidary-api/src/likeness.rs`,
  `crates/lapidary-api/tests/likeness.rs`. Not `repo.rs`, not `lib.rs`'s route list (W0 merged `likeness::routes()`).
- Ranking and clustering are pure functions with their own unit tests; SQL only fetches candidates.
- Implement `pub(crate) async fn clusters(db, library, since)` exactly as W0 declared it — G4 calls it.

## Stages

1. **Reads** — profiles by library; candidates in the ±2% size band; identical by current source `blake3`; links of a
   part. **Routes:** `GET /api/parts/{id}/likeness?limit=24`, `GET /api/libraries/{id}/duplicates?since=`.
2. **Decisions** — `PUT` / `DELETE /api/parts/{id}/links/{other}` (`variant`, `distinct`); `POST /api/parts/{id}/fold`
   `{ into }` in one transaction (soft-delete by the `soft_delete` rule + a `folded_into` row);
   `GET /api/libraries/{id}/folds`.
3. **Tests** (synthetic profiles through `PgShapes::record`): identical-by-hash appears; a scaled copy is similar but
   not a near-duplicate; `distinct` and `variant` take the pair out of clusters, and a variant shows on both parts;
   pairs A–B and B–C make one cluster; fold soft-removes, Restore brings the pair back; fold refuses another library
   (404), itself (422), a removed target (404); removed parts are excluded; `since` filters.
4. **Measured:** 10,000 synthetic profiles, release build, warm — `/likeness` under 50 ms, `/duplicates` under 300 ms.
5. Mutation checks: the size band dropped; the `distinct` link ignored; fold without the soft delete.
